# European Air Traffic Operations Analytics Dashboard

## Overview

This project analyzes European IFR flight movements between 2016 and 2022 using Tableau.

The dashboard provides insights into airport performance, flight traffic distribution, seasonal demand patterns, and year-over-year operational trends.

## Tools Used

- Tableau
- Data Visualization
- Business Analytics

## Dashboard Features

- Airport-level traffic mapping
- Country-level traffic aggregation
- Top airport ranking analysis
- Monthly arrivals vs departures comparison
- Seasonal trend visualization
- Day-of-week traffic analysis
- Year-over-year growth analysis

## Key Insights

- Amsterdam Schiphol and Paris Charles de Gaulle consistently ranked among the busiest airports.
- Summer exhibited the highest IFR traffic volumes across the observed period.
- Friday showed the highest average flight traffic among weekdays.
- Flight movement trends demonstrated significant year-to-year variation across major European hubs.
